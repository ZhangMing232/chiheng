# 财报口径（EARNINGS）

> ⚠️ **能力缺口（不是等价实现）**：Vibe-Research 的完整财报拆解要求绝对值科目
> （营收/归母/扣非/EPS）+ 三表明细。赤轨只有三个**累计口径的比率**，所以单季拆解、
> TTM、环比、杜邦全部做不了。缺的那块要接三表数据才能补（GAP-REPORT D2，待用户拍板）。
> 在此之前，本手册只能回答「累计口径上发生了什么转向」，回答不了「为什么」。
>
> 学 Vibe-Research 的 `.agents/skills/earnings-analysis/SKILL.md`（82 行）。

## 0. 三条铁律

1. **序列按公告日期排，不按报告期**。同一报告期可能补披露、修正，后公告的修正前面的；
   按报告期排会把修正版排到旧版后面——这是 PIT 的老坑。
2. **只描述发生了什么，不推测原因**。毛利率下滑是降价还是成本涨，比率里看不出来；
   要三表明细，赤轨没有。让 AI 补一个听起来合理的原因，就是编。
3. **少于 2 个报告期就不判断**，写缺口。一期数据没有「趋势」可言。

## 1. 赤轨有什么、没什么

| 有 | 字段 | 口径 |
|---|---|---|
| 净利润同比增长 | `dtYoy` | **累计口径**（报告期累计） |
| 销售毛利率 | `gm` | 累计口径 |
| 净资产收益率 | `roe` | 累计口径 |
| 公告日期 | `ann` | PIT 的关键 |

| 没有（所以以下全做不了） | 后果 |
|---|---|
| 营收 / 归母 / 扣非 / EPS 绝对值 | 算不出单季、TTM、PE 分子、PEG |
| 三表明细（现金流 / 应收 / 存货 / 负债） | 拆不开杜邦、看不出毛利率下滑的原因 |
| 资产负债率（东财接口不给，恒 null） | 偿债能力这一段是空的 |

**数据来源**：`scripts/fetch-fundamentals.py` → `data/backtest/fundamentals.json`
（2026-10-12 实测：7 个报告期、11636 只票、每条带公告日期）。

## 2. 转向判断（代码定，`earnings-sop.ts`）

| 观察 | 判读 | 必须叠加 |
|---|---|---|
| 净利润同比连续两期为正 | 累计口径连续为正 | 可能来自低基数，不一定是经营改善 |
| 净利润同比由正转负 | **本期最硬的转向信号** | 仍是累计口径，单季可能已先转负 |
| 毛利率连续两期下滑 | 连续下滑 | 看不出是降价还是成本涨 |
| ROE 连续两期下滑 | 连续下滑 | 分不清利润率 / 周转 / 杠杆（杜邦要三表） |

每条判读都带 caution，**没有 caution 的推断不允许出现**——这是 `AI-BOUNDARY.md`
「强结论先找反证」的落地。
