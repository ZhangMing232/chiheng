# 催化剂与风险口径（CATALYST-RISK）

> ⚠️ **能力缺口（不是等价实现）**：Vibe-Research 的催化剂有「预期型」（依赖一致预期
> 修正方向和研报覆盖数）、风险分类有十项（含融资融券/股东户数/解禁表）——赤轨这些
> 数据全没接（GAP-REPORT D1/D3/D4，待用户拍板）。所以本手册只覆盖「兑现型/周期型/
> 资金情绪型」催化剂和一半风险分类。**风险清单缺了一半，这点必须明说。**
>
> 它把「风险」从一段泛泛的文字变成**可核对的清单**，这条完全采纳。
> 差异在落地：它的裁决点靠提示词约束 AI 遵守，赤轨把推导做成了代码
> （`src/lib/market/catalyst-sop.ts:decisionPointsFrom`），每份报告一定有 ≥3 个裁决点。

## 0. 三条纪律

1. **强结论必须先找反证**。任何「充足 / 不是问题 / 确定」的说法，必须同时给出
   什么数据会推翻它；找不到反证，结论才成立。
2. **催化剂必须带来源和时点**。写不出来下一次公开时点的，不算催化剂，只算叙事。
3. **不给投资动作**。「风险高」不等于卖，「催化剂多」不等于买。产出只到情景概率与裁决点。

## 1. 催化剂分类（赤轨能观察的）

| 类型 | 含义 | 赤潮观察数据 |
|---|---|---|
| 兑现型 | 已有订单 / 产能 / 认证在落地 | 公告（巨潮）、财报 |
| 周期型 | 行业周期位置变化 | PE/PB 历史分位、d20/d60 位置 |
| 资金 / 情绪型 | 资金流、成交热度 | 当日主力净额、成交额——**只作温度计，不作结论依据** |

**预期型（市场尚未形成一致预期的变化）赤轨没有数据**——它依赖一致预期修正方向和
研报覆盖数，这两个端点赤轨都没接。**不许拿记忆里的「市场预期」填空。**

## 2. 风险分类与反证

| 风险 | 当前证据 | 反证要看的数据 |
|---|---|---|
| 周期顶 | 利润在峰值而 PE 最低 | PE/PB 分位 + d20 方向（见 VALUATION.md §4） |
| 治理 / 合规 | 减持、质押、问询函、退市风险 | 巨潮公告（法定披露平台） |
| 流动性 / 交易结构 | 成交额萎缩、换手异常 | 当日成交额、换手率——只作温度计 |
| 数据源冲突 | 同一事实多源不等 | 报告里逐条列出各源值与来源，**不静默取舍** |
| 数据缺口 | 关键端点失败 / 部分 | 写进缺口清单并说明对结论的影响 |

**赤轨没有的**：一致预期下修（需两次 fetch_estimates 对比）、融资余额、股东户数、
解禁表、龙虎榜历史——都不写，需要就列进缺口。

## 3. 裁决点（代码推导）

裁决点 = **什么数据出来会改变判断**，不是「关注后续进展」。四个要素：

1. 观察对象（具体指标或事件）
2. 阈值或方向
3. 数据来源 + **下一次公开时点**
4. 触发后判断怎么变

`decisionPointsFrom(stages)` 从六阶段证据推导：某阶段没有证据就不出对应裁决点，
转而出一条「补数据」的裁决点（只出一条，列多了像免责声明）。

## 4. 与 verdict 阶段的关系

研判页第六阶段的产出**全部**来自 `decisionPointsFrom`，不手写。手写列表会漏
（没考虑某阶段到底有没有证据），而且无法单测。

## 5. 产出

- 裁决点清单（≥3 个，四要素齐全）
- 强结论 → 反证对照（结论 / 反证 / 是否降级为情景）
- 数据源冲突清单、数据缺口清单
- 情景概率（如需）：用区间不用单点，写明依据
