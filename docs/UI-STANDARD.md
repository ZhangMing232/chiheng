> 越差，甚至得完全推倒重做」。本文档把赤轨**现有**约定固化下来——不是发明新规范，
> 是把已经在代码里的取舍写成条文，新页面照此施工，改动前必读。
>
> v1.1（2026-10-12）学 Vibe-Research 的桌面端：它的设计语言（语义 token、卡片+
> 口径说明、缺口显式、来源行、低频折叠）与赤轨 v1 同构，方向被验证。新增
> 第 7 节「来源与口径」（U1-U5）——是**增补条款**，不推翻 v1 任何条目。

## 1. 设计令牌（语义类名，禁止裸色值）

赤轨用 Tailwind 语义 token（`text-muted`、`bg-surface`、`border-line`、`text-warn`、
`text-fg`）。规矩：

- 新代码**只用语义类名**，禁止写死的 `text-gray-500` / `#xxxxxx`（图表 canvas
  等没法用类名的场合除外，且要在注释里说明为什么）。
- 语义 token 的增改在 Tailwind 配置层做，一次改动全站生效；不许在页面里
  「临时」引入新色值然后留下来。

**★红涨绿跌是 A 股铁律**：收益为正 → 红，为负 → 绿。禁止美式红跌绿涨。
检查方法：搜 `#C0392B|#0F6E56` 或直接看渲染，拿不准就问。

## 2. 布局

- **首屏 ≤1 屏**：主结论数字放大放前面（因子页的「N 个里 M 个」是范本）。
- **低频内容一律折叠**：`<details>` 或 `collapsible.tsx`，默认收起——第一眼
  清爽，功能不丢。用户明确点过「要折叠」的诉求不许回退。
- Tab 子页面只渲染选中那个区块，七个全挂 DOM 的老做法已废（factors.tsx）。

## 3. 组件

| 组件 | 规范 |
|---|---|
| 空态 | `StateBlock`：「没有数据」必须同时给**为什么 + 怎么补**（重跑命令/开关位置）。禁止空白页、禁止空集合冒充「0」。 |
| 徽标/强调 | 过关 ✅ / 淘汰 ❌ / 衰减 ⚠️ 用 emoji + 语义色，全站一致。 |
| 数字 | 大数字用 `clamp()` 流式（`clamp(28px, 4vw, 42px)` 范本）；表格数字右对齐。 |
| 表格 | 判据原话直接显示（「\|t\|=4.35 vs 临界 3.09」），不许只给 ✓/✗ 不说依据。 |
| 区块 | `Section`（title + hint）：hint 写「这区块是什么 + 数据从哪来」，不写字面重复 title 的话。 |

## 4. 文案纪律

- **同一句话只写一处**：六关图例（GATE_LEGEND）、可交易闸文案、披露口径，
  都由 lib 层出，页面只消费——发现两处文案说的是同一件事，抽成一个来源。
- **缺数据的样子就是缺**：`pass: null` 渲染「—」，禁止补成 ✗ 更禁止补成 ✓
  （factors-view.ts 的铁律，测试钉着）。
- 判据、出处、命令（可复制的）写全：引用回测数字必须带 baseline 文件名。

## 5. 数据契约

- 页面数据全部走 server function / 本地产物文件，**前端不藏业务常量**。
- server function 读不到数据要带回 `why`（data-status.ts 的 `Notice` 三问：
  为什么 / 影响 / 什么时候恢复），页面照实说，不许静默吞。
- data/ 不在 git 里：换机器必然读不到，空态文案里要自带重跑命令。

## 6. 改动纪律

改本文档 = 改全站契约。新增组件/新 token 先进文档再进代码；推翻旧条目
要在条目下留「作废于 + 原因」，不许悄悄删。

## 7. 来源与口径（v1.1 增补，学 Vibe-Research）

- **U1 口径说明是一段话，不是一行**：关键卡片（因子面板、六关、AI 管理、
  回测结果）标题下除 hint 外，允许放一段「规则原文 + 防误读声明」
  （范本话术：「档位/判据是固定规则，不代表可持续，也不是推荐」）。
  一段说不清的区块，说明区块切错了，不是把话写长的理由。
- **U2 来源行三件套**：凡是从外部接口/缓存取数的卡片，底部来源行必须带
  ①取数时间（注明时区）②是否用的缓存 ③来源原名原样显示（接口截断/改写
  的字段名不替用户「修正」）。
- **U3 「没取到的」是独立区块**：主数据到了但个别字段缺，显式列缺口清单；
  禁止拿 0 或 ✗ 凑（与第 4 节「缺数据的样子就是缺」同源，补的是**部分缺口**
  的样式）。
- **U4 数据卡片带「重新取」旁路按钮**：title 写明何时该绕过缓存（例：
  「今天的涨停池不用缓存」）。重取失败要带回 Notice 三问，不许静默。
- **U5 首页常驻 AI 入口**：首页底部放「AI 控制台」区块，示例卡逐张对应 /ai 上的
  真实动作（接口配置/进化控制台/Token 监控/待验队列），点击带锚点跳过去。
  **不做自由文本对话输入**——赤轨的 AI 是「它提议、闸门说了算」的闭环
  （AI-BOUNDARY.md），没有对话接口；造一个输入框等于造假。若未来接入对话
  能力，入口形态照本条扩，不许在首页另起一套会话状态。

## 8. 边栏与全局外壳（v1.2 增补，对照 Vibe-Research 截图逐项补齐）

- **U6 边栏项带图标**：`SIDEBAR` 每项一个 lucide 图标（`nav.tsx` 一处定义，
  顶栏页面名复用同一张表）。图标语义对得上页面就行，禁止为图标再引第二个库。
- **U7 分组可折叠**：分组标题是按钮 + ChevronDown，折叠状态记
  `localStorage["chiheng-nav-closed"]`，默认全开。读 localStorage 只能在
  effect 里做（SSR 阶段没有它，和 AlertBell 已读水位同一个坑）。
- **U8 边栏底部常驻「接入 AI」**：brand-soft 垫底 + brand-text 文字，全站
  仅有的两处大面积品牌垫底之一（另一处见 U5 的首页 AI 大卡）。正文其余
  区域仍是中性灰——「颜色是稀缺资源」不因学 Vibe 的视觉而放松。
- **U9 顶栏当前页面名**：桌面端搜索框左侧显示「分组 / 页面名」（范本：
  Vibe-Research 的「工作空间 / 首页」）。数据来自 `navHit(path)`，和边栏
  激活态共用一张表，两处永不许各自维护。窄屏不显示（顶栏已有 logo）。
- **U10 首页 AI 大卡**：U5 的「AI 控制台」升级为 brand-soft 垫底的
  `<section>`（不再是 Panel）：品牌竖条 + 「今天，想让 AI 做什么？」+
  一句口径（AI 只提议、闸门判决）+ 四张 surface 白卡。对应 Vibe-Research
  首页的橙色大卡位；卡片仍逐张锚点跳 /ai 真实动作，不做对话输入框。
