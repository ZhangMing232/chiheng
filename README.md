# 赤衡

A 股观察工具。只保留一套已冻住的「启动前期」规则，收盘后把当天名单和沪深 300 记在浏览器里。记满 60 个交易日之前，默认空仓，不把记录说成成功率。

这不是投资建议，也不会下单。

## 规则

- 今日涨幅 1%–4.5%，5 日 0–8%，20 日 -3%–12%，60 日 -10%–25%
- 量比 1.2–2.8，换手 1.5%–12%，收盘成交额至少 5000 万
- 不选 ST，不碰涨跌停
- 预计持股 5–10 个交易日
- 买入时段只看早盘 9:25–9:30 和尾盘 14:40 以后

门槛不再按回测结果修改。

## 本地运行

```bash
npm install
npm run dev
```
