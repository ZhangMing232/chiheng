# 赤衡

A 股观察工具。只保留一套已冻住的「启动前期」规则。记满 60 个交易日之前，默认空仓，不把记录说成成功率。

这不是投资建议，也不会下单。

## 规则

- 今日涨幅 1%–4.5%，5 日 0–8%，20 日 -3%–12%，60 日 -10%–25%
- 量比 1.2–2.8，换手 1.5%–12%，收盘成交额至少 5000 万
- 不选 ST，不碰涨跌停
- 预计持股 5–10 个交易日
- 买入时段只看早盘 9:25–9:30 和尾盘 14:40 以后

门槛不再按回测结果修改。

## 部署到自己的电脑

需要 Node.js 22 或更新版本。Windows、macOS、Linux 都用同一组命令。

```bash
git clone https://github.com/ZhangMing232/chiheng.git
cd chiheng
npm install
npm run build
npm run serve
```

服务监听 `0.0.0.0:8787`。本机打开 http://127.0.0.1:8787 。同一 Wi-Fi 下的手机，用这台电脑的局域网 IP，例如 http://192.168.1.20:8787 。

窗口不要关。电脑关机或休眠，服务会停。交易日早上 9:20 前开机，并保持到 15:40，才会自动记下早盘、尾盘和收盘名单。记录写在项目里的 `data/journal.json`，不依赖浏览器一直开着。

换端口：

```bash
PORT=9000 npm run serve
```

## 开发

```bash
npm install
npm run dev
```

开发地址是 http://127.0.0.1:8080 ，不会自动记账。自动记账只在 `npm run serve` 里。
