# 赤轨

A 股选股。五套策略分开记账，每套最多 10 只。现价打到买入价才记入，打到卖出价或止损价再卖。买入当天不能卖。

这不是投资建议，也不会下单。上涨占比在样本记满之前只是样本。

次日补涨在 14:30 冻结当天最强的三个概念板块里的次强。那之前标的是预估价，不是买入价。

## 部署到 Mac mini

需要 Node.js 22。交易日电脑要开着、联网，至少从 9:30 到 15:00。14:30 不能休眠，否则补涨按开机后第一次看到的名单冻结。

```bash
git clone https://github.com/ZhangMing232/chiheng.git
cd chiheng
npm install
npm run build:mac
npm run install:mac
```

`install:mac` 会在登录时启动，崩了会再拉起来。页面在 http://127.0.0.1:8787 。每个人一本账，放在 `data/books/用户id.json`，不进 Git。收盘后按用户复制到本机 `chiheng-backup`。现在没有打开注册，这台 Mac 用的是 `dev-user`。原来的 `data/journal.json` 会在第一次记账时复制过去，之后不再改它。以后若开放注册，新用户从加入当天另记一本，不会继承已有成交。行情仍然只拉一份。策略和偏好仍是全站共用，不随用户改。打到买入价、止损价或卖出价时，账本自动成交，同时弹一条通知。通知只是提醒，成交记在本机账上，不会发到券商。到期该卖也会自动记一笔，并提醒一次。资金页只供复盘，不改变买入条件。选股页抬头写着上次记账时间，超过 3 分钟没有更新会标成记账中断。改了代码要重新 `npm run build:mac`，再执行一次 `npm run install:mac`。桌面图标在 Mac 上执行 `npm run app:mac`，桌面会有「赤轨.app」。双击只开窗口，关掉窗口不会停止记账。

只想先手动看一眼：`npm run serve`。开发用 `npm run dev`（http://127.0.0.1:8080），不会自动记账。

系统设置里把接通电源时的睡眠关掉。
