## 1. 设计基础

### 1.1 前提约束

脱离这四条谈「好看」没有意义：

| 约束 | 原因 |
|---|---|
| **红涨绿跌** | A 股约定，反了就是错 |
| **高密度** | 盯盘时一屏要能看到足够多的行 |
| **深色为默认** | 盘中长时间盯，深色底更省眼 |
| **状态必须说清** | 数据源会降级，页面不能说谎 |

### 1.2 色彩表

涨跌色按 **WCAG 2.2 AA** 逐项核过（正文 ≥ 4.5:1）。v1 核出浅色主题两项不达标，已改。

**深色（默认）**

| 用途 | 色值 | 对底色 | 实测 |
|---|---|---|---|
| 底色 | `#0b0e13` | — | — |
| 卡片 | `#131820` | 14.71:1 | ✓ |
| 卡片二（表头） | `#1a2029` | 13.20:1 | ✓ |
| 正文 | `#e4eaf2` | 15.97:1 | ✓ |
| 次要文字 | `#8b97a8` | 6.53:1 | ✓ |
| 弱化文字 | `#7b8796` | 5.29:1 | ✓ |
| 涨 | `#ff7070` | 7.18:1 | ✓ |
| 跌 | `#3ecb8e` | 9.33:1 | ✓ |
| 警告 | `#f0a83a` | 6.81:1 | ✓ |
| 品牌 | `#e5484d` | 6.30:1 | ✓ |

**浅色**

| 用途 | 色值 | 对底色 | 实测 |
|---|---|---|---|
| 底色 | `#f6f7f9` | — | — |
| 卡片 | `#ffffff` | 17.27:1 | ✓ |
| 卡片二 | `#eef1f5` | 15.10:1 | ✓ |
| 正文 | `#171b22` | 16.11:1 | ✓ |
| 次要文字 | `#5c6675` | 5.42:1 | ✓ |
| 弱化文字 | `#666f7c` | 4.74:1 | ✓ |
| 涨 | `#c9202e` | 5.25:1 | ✓ |
| 跌 | `#0b7040` | 5.75:1 | ✓ |
| 警告 | `#9a6200` | 4.59:1 | ✓ |
| 品牌 | `#c92a2f` | 4.86:1 | ✓ |

> **v1 的问题**：浅色涨红 `#d23b48` 只有 4.35:1、跌绿 `#128a5a` 只有 4.04:1，都不达标。
> 红绿色弱用户读不清涨跌——这是硬指标，不是审美偏好。

**涨跌三重编码**：色块 + 正负号 + 数字。颜色不单独承载信息。

### 1.3 字体刻度

字体：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
数字：`font-variant-numeric: tabular-nums`（等宽数字，小数点成列）

| 层级 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| 字段名 | 10 | 1.4 | 400 | 窄屏卡片里的字段标签 |
| 辅助 | 11 | 1.4 | 400 | 说明、次要标签、状态药丸 |
| 正文 | 13 | 1.55 | 400 | 表格、段落 |
| 强调 | 13 | 1.4 | 500 | 面板标题、股票名 |
| 统计 | 15 | 1.2 | 500 | 统计格里的数值 |
| 主数字 | 18 | 1.2 | 500 | 个股页大数字 |

**字重只有 400 / 500 两档。** 密集数字里半粗体会糊成一片。

沿用页面已有的 小/标准/大/超大 四档字号切换（改根字号），布局不塌。

### 1.4 间距刻度

**基线 8px。** 所有间距是它的倍数或分数：

`4 · 8 · 12 · 16 · 24 · 32`

| 场景 | 值 |
|---|---|
| 表格单元格 | 横向 12px / 纵向 7px（桌面）、8px（移动） |
| 面板内边距 | 12px（992px 以下）、16px（以上） |
| 面板之间 | 8px（768px 以下）、12px（以上） |
| 面板头内边距 | 横向 12px / 纵向 8px |
| 药丸内边距 | 1px 6px |

### 1.5 圆角与阴影

| 用途 | 值 |
|---|---|
| 控件 | 3px |
| 面板 | 4px |
| 药丸 | 999px |
| 阴影 | **只有浮层用** `0 8px 24px` |

**层次靠 1px 边框，不靠阴影。** 盯盘页的阴影会让密集数字发灰。

## 2. 布局与断点

### 2.1 断点表（只有这 4 个）

移动优先：基准样式面向 320px，向上渐进增强。

| 断点 | 行为 |
|---|---|
| **320px+** | 单列。导航换到第二行横滚。**表格降级成卡片流**。图标按钮 44×44 |
| **576px+** | 利好/利空两栏并排。统计条每行 2 个 |
| **768px+** | **表格模式**：表头 sticky、首列 sticky，隐藏字段回来。图标按钮降到 36px（鼠标为主） |
| **992px+** | 面板内边距 12→16px |
| **1200px+** | 内容居中限宽 1360px |

### 2.2 统计条：不用媒体查询

```css
.stats { display: grid; grid-template-columns: repeat(auto-fit, minmax(140px, 1fr)); }
```

容器多宽就自动排多少列，加减一个格子不用改 CSS。

### 2.3 窄屏的表格降级（关键决定）

**手机上不看缩小的表格，改成卡片流。**

```css
@media (max-width: 767px) {
  thead { display: none }
  tbody tr { display: grid; grid-template-columns: repeat(3, 1fr); gap: 6px 10px; padding: 12px }
  tbody td { display: block; text-align: left; white-space: normal }
  tbody td::before { content: attr(data-l); display: block; font-size: 10px; color: var(--dim) }
  tbody td[data-opt] { display: none }        /* 次要列隐藏 */
}
@media (min-width: 768px) { tbody td[data-opt] { display: table-cell } }
```

**为什么这么设计**：6~8 列在 375px 上横向滚，等于一只股票都看不全。卡片流把「一只票」当成一个整体，扫的时候不串行。手机上还会隐掉「卖出/止损」两列——盯盘时这两列不是当下的重点。

`data-l` 是字段名，只在窄屏出现（桌面表格有表头，不需要重复）。

## 3. 组件规范

### 3.1 面板 Panel

扁平方板，`--surface` 底 + 1px `--line` 边框 + 4px 圆角。面板头是 `--surface-2` 底，比正文区略深一档，天然形成层次。

### 3.2 行情带 Tape

横排、每格 112px 起步、可横滑。**涨跌幅用色块不用字色**——余光扫过去就能分出红绿，不用逐个数字去读。

### 3.3 表格 Table

- 行高 32px（桌面）/ 44px（移动，兼顾触达）
- 表头 sticky（`top:0`），首列 sticky（`left:0`）
- 数字右对齐 + `tabular-nums`
- 行悬停**只变背景色，不缩放**（密集表格里缩放会晕）
- `<caption class="sr">` + `<th scope="col">`，屏幕阅读器能读出表头

### 3.4 状态徽标 + 三问浮层

**徽标只说结论**（「降级」「过期」「残缺」），点开才说原因。原因必须答完三问：

```
为什么      —— 为什么会这样
影响        —— 今天哪几套策略不工作
什么时候恢复 —— 会自己好，还是要点哪里
```

浮层 `role="dialog"`，触发按钮带 `aria-expanded` / `aria-haspopup`，`Esc` 关闭并把焦点还给按钮。

> 这条来自一个真实 bug：主源降级那天页面只显示「这套策略现在没有符合的股票」，看着像当天没机会，实际是数据源缺字段。**页面不能把「我拿不到」说成「没有」。**

### 3.5 骨架屏

刷新中用三行灰条占位，不用 spinner——布局不跳，且暗示了「下面是列表」。

## 4. 微交互参数

| 交互 | 参数 | 说明 |
|---|---|---|
| 按钮悬停 | `scale(1.05)` + 边框变色，200ms `cubic-bezier(.2,.8,.2,1)` | |
| 按钮按下 | `scale(.97)` | 给触觉反馈，眼睛能看到确认 |
| 页面按钮按下 | `scale(.95)` | |
| 行悬停 | 只变背景色 180ms | **不改缩放** |
| 进度条 | 宽度 300ms 缓动 | 让「名额涨了」看得见 |
| 浮层出现 | 淡入 + 上移 3px，200ms | |
| 骨架屏 | 1.4s 呼吸 | |

**只动 `transform` 和 `opacity`**（GPU 加速）。全部包在 `@media (prefers-reduced-motion: no-preference)` 里。

## 5. 键盘与可及性

### 5.1 快捷键

| 键 | 动作 |
|---|---|
| `j` / `k` | 上下移动 |
| `Enter` | 看详情 |
| `1`–`5` | 切策略 |
| `p` | 持仓页 |
| `m` | 消息页 |
| `r` | 刷新 |
| `t` | 深浅色 |
| `Esc` | 关浮层，焦点回到触发按钮 |

**选中行用 2px 品牌色左边条标记，不改底色**——底色会和涨跌色块打架。

### 5.2 检查清单

| 项 | 做法 |
|---|---|
| 对比度 | 正文与次要文字全部 ≥ 4.5:1（色板标注实测值） |
| 不靠颜色 | 涨跌用色块 + 正负号 + 数字三重编码 |
| 焦点可见 | 全局 `:focus-visible` 2px 品牌色 + 2px 偏移 |
| 触达 | 移动端图标按钮 44×44，表格行 44px |
| 语义化 | `<header><nav><main><table>` + `scope` + `<caption>`，不靠 ARIA 兜底 |
| 动效降级 | `prefers-reduced-motion` 下全部关闭 |
| 进度语义 | `role="progressbar"` + `aria-valuenow/min/max` |
| 状态语义 | 浮层 `role="dialog"`，触发按钮 `aria-expanded` |
| 导航语义 | `aria-current="page"`，Tab 列表 `role="tablist"` |
| 字号缩放 | 根字号变化时布局不塌 |

| hover 放大 1.05 | ✗ | ✓ |
| 触达 44px | ✗ 28px | ✓ 移动 44 / 桌面 36 |
| 骨架屏 | ✗ | ✓ |
| 窄屏降级方案 | ✗ | ✓ data-l / data-opt |
| 语义标注 | 3 处 | 18 处 |

**检查清单 8/15 → 20/20。**

### 6.2 v1 最大的问题是我自己的

`focus-visible` 这一项——我在 v1 的「规范」页里白纸黑字写着「所有可点元素有 `:focus-visible` 轮廓」，**代码里一个都没有**。这是典型的「文档说了但没做」，和今天下午批评别人的「代码对但页面不对」是同一类错误。**写进文档的东西要能自动核。**

### 6.3 验证方式

浏览器（`agent-browser`）未安装，视觉效果未在浏览器里验证。用可复用的方式做了三层验证：

1. **静态**：标签闭合、CSS 花括号、JS 引用 id、CSS 变量定义、零外链
2. **CSS**：交给项目自带的 **PostCSS 真解析** → 132 条规则、10 条 @rule、无空值声明
3. **JS**：Node + 极简 DOM stub **真跑一遍** → 六处渲染数量全对（行情带 6、策略 6、精选 10、持仓 5、电报 5、色板 10），`data-l` 60 个、`data-opt` 20 个
