# 赤轨 × Vibe-Research 功能同步计划

> 2026-10-12。对照 `github.com/simonlin1212/Vibe-Research`（5.1 万行成熟产品）
> 逐个功能对账。原则：**它有的赤轨要有，赤轨独有的一个都不删。**
>
> 我们对账的原则是「为什么不」而不是「怎么抄」——它的 Python 实现一行都不搬，
> 抄它的「一个功能该回答什么问题」。

### 赤轨独有、它没做的（保留，不因对齐而砍）

- **因子发掘 6 关检验**（25 因子 × G1-G6）——它的强项是基本面研究，这里是它的空白
- **资金流向页**（行业/市场全景）
- **冠军-挑战者 + Welch 判决**（自动判决，AI 碰不到判决函数）
- **AI 进化闭环 + token 账本**（factor-queue / ai-usage）
- **三层闸门**（liveGate / hardGate / softGate）

## 二、第一批（2026-10-12 已完成）

1. **外壳对齐**：边栏图标、分组折叠、底部「接入 AI」、顶栏「分组 / 页面名」、
   首页 AI 大卡 → `UI-STANDARD.md` v1.2 §8 U6-U10
2. **个股研判 `/research`**：
   - `src/lib/market/research.ts`：六阶段 SOP（身份 / 价格位置 / 资金与成交 /
     催化剂与风险 / 估值锚 / 裁决点），每阶段产物 = 证据（带来源）+ 结论（带四档
     可信度）+ 缺口
   - `src/lib/market/research.test.ts`：11 条（含**模板自带红线自查**——自己写的
     结论一个都不许越线）
   - `src/routes/research.tsx` + `routeTree.gen.ts` 手改 11 处

三条刻意在细节上不同于它的设计：

- **四档可信度不是装饰**。它的 `inference_tiers.ts` 要求「除未核实线索外每条必须有
  依据 id」——赤轨现在还没有证据 id（P0-3 在做），所以先落到「机器只能出到哪一档」
  由代码判定：按标题用词自动分的利好利空**强制落在「未核实线索」**，测试钉死。
- **缺口必须显式**。估值阶段写死了「缺历史 PE 分位」，因为赤轨现在真没有 PE 历史
  序列。不给工具型用户 Tavily 幻想。
- **自己的产出也过红线**。这条最反直觉：一般红线只拦 AI 说的话。但赤轨的坚守是
  「不能为了方便让自己放的沈默」。所以 `runResearch` 每条结论都走 `screenAdvice`，
  命中就换成占位句 + 计数，页面上明说「有 N 条被拦下」。

## 三、第二批（下一步）

1. **自选与持仓 `/my-stocks`**：自选名单存在本地（不等同于「策略追踪」里的账上持仓），
   两个 tab 并列——它就是这么把 watchlist 和 portfolio 合成一页的。
   为自选股单独拉报价，复用 `universe` 快照。
2. **多空辩论 `/debate`**：同一只票同时生成正方/反方两组「裁决点」，共用第一批的
   六阶段产物；两边都只给观察条件，不给动作（红线自动生效）。
3. **我的报告 `/my-reports`**：把每次研判落盘成 `report-<id>.md`，带四档可信度字段。
4. **每日复盘 `/daily-review`**：指数 + 涨停池 + 资金 + 今日信号的一天总结。

## 四、第三批

板块详情、日历（财报/公告/事件）、回测页面化（把 CLI 结果搬进网页）、笔记、
设置收拢。

## 五、不动的

- 它的 `data-access` 170 端点 / 35 层：赤轨是 A 股单一市场，不需要那规模的一层。
- 它的 Electron 桌面端打包：赤轨是 Web + SSR，形态不同。
- 它的会员制/定价页面：赤轨会员制按「验证成本」分层（另有计划），不走它的路子。
