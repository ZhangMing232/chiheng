# 赤轨 UI 升级方案 · 2026-10-26

定位：A 股研究与策略进化工具。方向：深色研究终端 × 数据杂志排版。
不可违背约束：预登记纪律 / 数字有出处且回测无前视 / 红涨绿跌。

---

## 1. 设计规范

### 1.1 颜色（CSS 变量，全局唯一来源）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-0` | `#0C0D10` | 页面底（墨黑，非纯黑） |
| `--bg-1` | `#12141A` | 面板 |
| `--bg-2` | `#1A1D25` | 抬升（hover / 弹层 / 选中行） |
| `--line` | `rgba(255,255,255,.07)` | 分隔线（发丝级，不描边感） |
| `--text-0` | `#EDEFF4` | 主文字 |
| `--text-1` | `#9AA1AD` | 次要 |
| `--text-2` | `#5D6472` | 弱化 / 脚注 |
| `--accent` | `#E64B33` | 朱砂点缀：**只**用于关键状态、温度计热端、唯一主强调 |
| `--accent-dim` | `rgba(230,75,51,.14)` | 点缀的底色承载 |
| `--up` | `#E84D4D` | 涨（ refined 红，不用 #F00 系） |
| `--down` | `#43A583` | 跌（ refined 玉绿） |
| `--warn` | `#D9A441` | 饱和/异常提示（非涨跌语义） |

面板质感：bg-1 + 1px 内高光 `inset 0 1px 0 rgba(255,255,255,.04)` + 8~12px 圆角 +
极淡阴影。**不做**玻璃模糊堆叠、不做彩色描边卡片。

### 1.2 字体层级（杂志式拉距）

- 数字一律 `font-variant-numeric: tabular-nums`（表格对齐是信任感来源）
- 展示数字（hero numerals）：40–64px / 300 字重 / 紧行高，用于温度计分数、指数、超额
- H1 页面题：22px 衬线（`"Songti SC","Noto Serif SC",Georgia`）——杂志感的来源，全站仅此一处用衬线
- H2 分区题：14px 全大写感 + 2px 字距（中文则加字距）
- 正文 13px / 辅助 12px / 脚注与出处 11px text-2
- 密度：舒适 13/40、紧凑 12/32 两档，表格可切换（偏好记忆）

### 1.3 签名视觉（强识别三件套）

**① 市场情绪温度计（全站最强组件）**
横向五档量柱：冰点 #5B8DB8 → 偏冷 #4FA3A0 → 温和 #B9A05A → 过热 #E8894A → 沸点 #E64B33。
中心一个 48px 综合分 + 状态词（冰点/偏冷/温和/过热/沸点）+ 一句话状态（如「沸点附近，追涨风险高于机会」）。
右下角「怎么算的」入口 → 弹层列出分量与出处。**当前档位的发光用 accent-dim，不用刺眼辉光。**

**② 进化生命条（因子/挑战者通用语言）**
- 因子：待验(灰) → 在验(蓝 #5B8DB8) → 过关(金 #D9A441) → 监控(金闪) → 衰减(橙) → 淘汰(墓碑 ⛏ 灰)
- 挑战者：x/30 细进度环（minTrades=30 为满环），提前否决倒计时「剩 N 天」；
  **名单饱和时显示 warn 徽标「池满，成交缓慢」**

**③ 判决可点开**
任何判决数字（6 关、t 值、Welch、超额）旁带 ⓘ，点开 drawer：判据原话、数据区间、
样本数、出处文件/回测 run id。诚实是产品的一部分。

### 1.4 统一状态五态（所有数据区强制）

Skeleton（骨架与版面同形）/ Empty（说明**原因**+行动按钮，如「今天非交易日」）
/ Error（可操作重试 + 错误原文折叠）/ Stale（右上角「截至 HH:mm」徽标 + 内容降透明度至 .55）
/ Partial（局部失败只灰那一块，旁边 ⓘ 说明）。每区独立，一区挂不拖累整页。

## 3. 首页（/home）布局

栅格 12 列，桌面单屏 1440×900 内 Zone A+B 可见，C 半屏，D 可滚。

```
┌─────────────────────────────── Zone A ───────────────────────────────┐
│ 指数条(4枚 大数字横排)      │  情绪温度计(主视觉,跨2列)  │ 今日关键数字 │
│ 上证 3,xxx.xx ▲0.00%       │  [五档量柱]               │ 涨/跌家数    │
│ (tabular, 点击→/symbol)    │   72 · 偏热               │ 涨停/跌停    │
│                             │  「一句话状态」 ⓘ计算说明   │ 成交额/北向  │
├────────────── Zone B ─────────────────┬──────── Zone C ──────────────┤
│ 资金流向快照(北向/主力/两融 3格)        │ 全球市场(迷你列表,克制的涨跌点) │
│ 风格规模表现(大小盘/价值成长 4宫格)      │ 产品与进化状态                │
│ 行业资金 Top5 流入/流出(双色条)         │ ●服务正常 · 今开x/平y        │
│                                        │ 挑战者 2/30 · 饱和⚠ · 异常0   │
├────────────── Zone D ─────────────────┴───────────────────────────────┤
│ 今日重要事件(最多3条) │ 热点词条(≤6) │ 最近查看(自选股,横向滚动)          │
└────────────────────────────────────────────────────────────────────────┘
```

规则落地：每区左上角 11px 脚注显示「更新于 HH:mm:ss」；数字全部可点下钻；
五态独立；全页无任何买卖建议文案（温度计的状态词用「风险/拥挤度」表述，不给方向指令）。

## 4. P0 落地清单（按序做，每一步都有成品感增量）

1. **设计令牌** `tokens.css` + Tailwind theme，红涨绿跌全局变量替换（半天）
2. **侧边栏 IA 重组**（新七组 + 旧路由重定向 + 组徽标：进化组在跑挑战者数）
3. **情绪温度计组件** `<SentimentGauge/>`（纯前端 + 现有情绪数据 hook，签名组件先做）
4. **首页 /home 四区**（全部复用现有数据函数，零新数据源）
5. **五态组件 `<ZoneState/>`** + 时间戳/降权，先应用到首页和进化页
6. **进化可观测三件套**：挑战者 x/30 进度环、池满饱和提示、因子死因/判决 ⓘ drawer
7. **⌘K 命令面板**（路由跳转 + 代码搜索直达 /symbol，复用 __root 现有 symbol 搜索逻辑）
8. **H1 衬线 + hero numeral 排版改造**（总览、进化控制台两页先吃，验证气质）

P1：表格三件套（排序/粘性/密度）、研究页事实/推断/待验证三段式标签、
全局快捷键、偏好记忆持久化。
P2：移动端单列布局与触控优化（你常手机看，建议 P1 后半插入）。

## 6. 需要你拍板的取舍

1. **studio 自媒体图文放哪**：建议归「资讯 → 内容台」降级入口；它和研究/进化的产品气质差距大，你之前也说过它制作慢。若你认为它是独立产品线，就保持一级隐藏入口。
2. **旧主控台 `/`**：建议直接由新首页替换（旧组件拆进四区）；若想保守，可并存两周再下线。
3. **字体**：衬线标题用系统 Songti/Noto Serif（离线可用、零加载）——放弃网络字体的极致质感，换本机服务的稳定性。认可？
4. **移动端**：P2 提到手机体验，但你经常外出用手机看。是否把「首页 + 市场 + 组合三页单列适配」提到 P1？
5. **管理页 /admin 与会员 /membership 的暴露**：现在侧栏对所有人可见。会员体系尚未开工，建议侧栏先藏入口（直链可进），等会员功能落地再亮出。可以吗？
