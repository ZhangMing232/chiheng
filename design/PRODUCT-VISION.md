## 二、目标定义（建议，等你确认）

### 产品一句话

> **赤轨 = A 股的「自动实验室」**：AI 大脑（harness）每天自己观察、诊断、提议，
> 六关闸门判决，把"选股—回测—复盘"变成不需要盯盘的产品；
> 会员买的是"AI 帮我做实验 + 全市场数据 + 研究报告"，不是买卖建议。

### 和两个 Vibe 的定位差异（这是产品立足点，不是差距）

| | Vibe Research / Trading | 赤轨 |
|---|---|---|
| 形态 | 开源 + 本地 + BYO-key，个人工具 | **SaaS：注册登录、会员分层、云端数据** |
| AI | 用户自己的 Claude Code/Codex/订阅 | 平台 harness（DeepSeek），**会员免配 key**，平台承担成本 |
| 数据 | 168 端点，用户自己拉 | 平台侧每日抓取落库，会员直接看 |
| 决策 | 人驱动 AI | **AI 提议 + 闸门判决 + 人拍板**（六关/Welch/挑战者，AI 只有请求权） |
| 收费 | 无 | ¥29 月 / ¥299 年 / ¥999 终身（MEMBERSHIP.md 已定） |

**核心卖点一句话**：把 Vibe 那套"要会折腾才能用"的能力，做成"注册就能用"的产品，
且 AI 的实验过程全透明（六关判决、证据引用、数字核验）——**避免黑箱是产品差异，
不是合规负担**。

### 商业模型（v1）

- 免费层：看行情/自选/复盘，AI 额度 0 或极低（体验产品形态）
- Pro 月/年：AI 大脑全功能 + 信号 + 事件 + 研报库 + 回测
- 终身：早期支持者回馈，限量或不主推
- **成本红线**：AI 调用是真金白银（DeepSeek API），额度闸已按 plan 限次数（7e74f23），
  上线前必须算清单用户月均成本 < 客单价（见 §3 P0-4）

## 四、需要你拍板的（按紧迫度）

1. **收款渠道**（阻塞 P0-1）：a) 爱发电类平台，零资质、抽成 5-10%、月结，一周能上；
   b) 注册个体户（几百块）+ 微信支付原生，费率 0.6%、T+1、要 1-2 周。
   **我的建议：先 a 后 b**——用 a 验证"有人愿意付钱"，再投资质成本做 b。
2. **AI 成本归属**：会员免费烧平台的 key（有额度闸，风险可控但烧钱），
   还是"免费层 BYO-key / Pro 含平台额度"的混合？建议后者，与两个 Vibe 的开放模式一致。
3. **部署位置**：a) WorkBuddy 云端发布（平台托管，最省事）b) 自己买轻量服务器
   （要自己运维）c) 先隧道+域名（REMAINING 留档方案，最临时）。建议 a。
4. **终身版是否主推**：¥999 终身早期回馈可以，长期是负债（AI 成本不会停）。建议限量或不卖。

## 五、和现有纪律的关系（不破坏的）

- 判决规则（六关/Welch/挑战者/额度闸）继续只认代码，AI 只有请求权
- 一切可视化、参数化（避免黑箱）；页面布局视觉体验优先
- 拿不到数据/拍不了板的事，说出来等决定，不自行裁剪
- 会员功能不影响单机模式：本机 PGLite + 个人账本永远可用（那是产品的"实验场"）
