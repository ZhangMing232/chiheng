## 4. 建设顺序（优先级）

**第一批（首页体感，先做）**
1. **①股市总览**：新建 `/overview` 或把 `/` 升级成总览仪表盘（指数卡片 + 涨跌分布 + 板块热力 + 资金 + 快讯 + 一键跳转）。数据都是现成的（universe-cache / flow / news）。

**第二批（信息聚合）**
2. **②小道消息/小作文聚合**：先做「聚合与分类」框架（来源标签 + 话题分类 + 态度），数据源从东财股吧/雪球热帖等公开页抓（需先探可行性），先落 UI 骨架 + 手动/半自动来源。

**第三批（AI 大管家 + 自媒体）**
3. **⑥AI 大管家**：新建 `/butler`（或增强 `/ai`）：常驻对话，接 DSH 桥接（`/chihengapi/chat`），给它挂上「读行情/读账本/读因子/读挑战者/读诊断」的工具路由，做到「问什么答什么、实时跟进」。
4. **⑦自媒体模式**：新建 `/studio`：选素材（海报已能生成）→ 加视频（先用 ffmpeg 合成图片序列/字幕，做 MVP）→ 下载。先落地「图片一键生成+下载」流，视频第二步。

**第四批（收尾）**
5. **管理系统** `/admin`（挂 Neon 后）。
6. **UI 借鉴**贯穿全程。
7. **注册登录收费**（最后，含 Neon + 支付回调）。
